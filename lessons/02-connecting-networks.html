01 · MENTAL MODEL

Build a mental model of how the key components fit together

Diagram cue: VPC peering is not transitive. Prefer Transit Gateway when many VPCs or hybrid attachments must route.
①Match topology to scale

Use peering for a few direct relationships and Transit Gateway for transitive hub-and-spoke routing across many VPCs and attachments.

②Separate path from encryption

Direct Connect supplies a private physical path but does not encrypt traffic by default; add VPN over DX when encryption is required.

③Publish one service

PrivateLink exposes a service through interface endpoints without sharing routes or requiring non-overlapping consumer CIDRs.

④Resolve across boundaries

Route 53 Resolver inbound and outbound endpoints bridge hybrid DNS; private hosted zones alone do not answer on-premises resolvers automatically.

03 · DEEP DIVE

What you actually need to understand

1

VPC Peering

  • Private point-to-point routing between two VPCs.
  • No transitive routing: A↔B and A↔C does not create B↔C.
  • Peered VPC CIDRs cannot overlap.
  • Routes must be added to relevant route tables and security controls still apply.
2

Transit Gateway

  • Hub-and-spoke routing for many VPCs and hybrid connections.
  • Transit routing is controlled with Transit Gateway route tables.
  • Reduces the operational complexity of a full peering mesh.
  • Can centralize inspection/egress patterns and aggregate VPN/Direct Connect connectivity.
3

Site-to-Site VPN

  • IPsec encrypted connectivity over internet paths.
  • AWS provides redundant VPN tunnels; design customer-side redundancy as well.
  • Good when encrypted connectivity is needed quickly.
  • Network performance can vary because the path uses the internet.
4

Direct Connect

  • Dedicated connectivity from your network to AWS through a Direct Connect location/provider.
  • Useful for consistent hybrid network performance and sustained data transfer.
  • Direct Connect traffic is not encrypted by default; add appropriate encryption where required.
  • For resilient critical designs, use redundant connections and/or VPN backup.
5

PrivateLink + Route 53

  • PrivateLink exposes a specific service privately rather than routing entire networks together.
  • Excellent provider/consumer pattern and useful with overlapping address spaces.
  • Route 53 is DNS, not a packet router: it tells clients which endpoint to use.
  • Know weighted, latency, failover, geolocation, geoproximity and multivalue routing patterns.

05 · WORKED SCENARIOS

Apply the concepts as an architect

WORKED SCENARIO

Build a transitive network hub

Dozens of VPCs and two offices need centralized, transitive routing with segmented route domains. Attach them to a Transit Gateway and use separate TGW route tables. A peering mesh grows quadratically and peering cannot route transitively through another VPC.

1 Transitive hub→2 Route domains→3 Fewer links
WORKED SCENARIO

Private predictable hybrid path

A data center transfers steady large volumes to AWS and requires consistent network performance, with encrypted failover. Use Direct Connect as the primary path and a site-to-site VPN as backup, adding VPN over DX if primary-path encryption is mandatory. VPN alone depends on internet conditions, while Direct Connect alone lacks native encryption.

1 Predictable path→2 Encrypted option→3 Backup route
WORKED SCENARIO

Expose only an internal service

A provider must serve hundreds of customer VPCs, including overlapping CIDRs, without granting broad network access. Put the service behind an NLB and publish it through PrivateLink endpoint services. Peering requires non-overlapping CIDRs and exposes routed network reachability beyond the single service.

1 Overlap safe→2 Service scoped→3 No route sharing

07 · KNOWLEDGE CHECK

Five SAA-style questions

Q1Fifty VPCs need transitive connectivity to each other and to on-premises networks with centralized route segmentation. Which service best fits?
Answer: B. The deciding constraints are transitive routing and scale. Transit Gateway provides a managed hub with multiple route tables.
Q2A partner must consume one TCP service privately from a VPC whose CIDR overlaps the provider VPC. The provider must not share network routes. What should be used?
Answer: C. The deciding constraints are overlapping CIDRs and service-only exposure. PrivateLink maps endpoint ENIs to a published service without routed connectivity.
Q3A company needs a dedicated, predictable path from its data center to AWS, but all application traffic must also be encrypted in transit. Which design works?
Answer: D. The deciding constraints are dedicated performance and encryption. Direct Connect supplies the path, while the VPN supplies IPsec encryption.
Q4On-premises DNS servers must resolve records in Route 53 private hosted zones. Which component accepts those DNS queries inside the VPC?
Answer: A. The deciding direction is on premises to AWS. A Resolver inbound endpoint receives forwarded queries for private AWS namespaces.
Q5Two VPCs have a peering connection, and one is connected to a third VPC. The first VPC cannot reach the third through the second. What explains this?
Answer: B. The deciding topology rule is that VPC peering is non-transitive; each required VPC pair needs a direct connection or a routing hub.
