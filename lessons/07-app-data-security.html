01 · ARCHITECTURE DRAWING

Build edge, encryption, secrets, and detection

ARCHITECTURE

Users

Internet clients hit the edge first. Packet filters that only exist on the origin never see blocked requests.

ARCHITECTURE

CloudFront + WAF

Terminate TLS at the edge if you want. WAF inspects HTTP at CloudFront or ALB. It is not Shield.

ARCHITECTURE

Shield

Shield Standard is on by default for DDoS. Shield Advanced is the paid operational/insurance layer. It does not replace WAF rules.

ARCHITECTURE

ALB + ACM

ACM issues and renews certificates for ALB and CloudFront. The origin is still in a VPC.

ARCHITECTURE

KMS

Key policy is foundational. IAM can only use a key if the key policy allows it.

ARCHITECTURE

Secrets Manager

Runtime secrets (DB passwords, API keys) with rotation. Not the same as KMS, which encrypts data keys.

ARCHITECTURE

GuardDuty

Threat detection from CloudTrail, VPC Flow Logs, and DNS. It detects; it does not filter packets.

ARCHITECTURE

The full security path

Users hit CloudFront + WAF + Shield, then ALB with ACM. Data keys come from KMS; app secrets from Secrets Manager; GuardDuty watches the account.

02 · DEEP DIVE

What you actually need to understand

1

KMS + encryption

  • KMS manages cryptographic keys used by many AWS services.
  • AWS-owned, AWS-managed and customer-managed key choices differ in control and administration.
  • Envelope encryption lets services encrypt data keys efficiently while KMS protects key material.
  • Key policies are fundamental authorization controls; IAM alone may not be sufficient depending on key policy design.
2

Secrets Manager

  • Stores secrets such as database passwords, API keys and credentials.
  • Supports rotation workflows for supported integrations/custom logic.
  • Applications retrieve secrets at runtime using IAM-authorized calls.
  • Do not confuse a KMS key with a secret value: KMS protects encryption keys; Secrets Manager stores secret material.
3

Edge + network security

  • AWS WAF evaluates HTTP(S) requests using rules and managed rule groups.
  • AWS Shield protects against DDoS; Shield Standard is built into supported AWS services, while Advanced adds expanded protections/features.
  • AWS Network Firewall filters VPC network traffic centrally.
  • Firewall Manager can centrally apply supported security policies across accounts/resources.
4

Detection + posture

  • GuardDuty analyzes signals to detect suspicious or malicious activity.
  • Inspector assesses supported compute/container/serverless workloads for vulnerabilities/exposure.
  • Macie discovers sensitive data in S3.
  • Security Hub aggregates and normalizes findings; Detective helps investigate security events.
  • Audit Manager and Artifact support audit/compliance evidence and reports.
5

Certificates + directories

  • ACM manages TLS certificates for supported AWS integrations.
  • Directory Service supports Microsoft AD and directory-integrated workloads.
  • Cognito manages application customer identity; IAM Identity Center handles workforce identity.
  • CloudHSM provides dedicated HSM appliances when direct HSM control is required.

04 · WORKED SCENARIOS

Apply the concepts as an architect

WORKED SCENARIO

Stop injection and bot requests

A public ALB receives SQL injection attempts and excessive requests from individual clients. Associate an AWS WAF web ACL with managed SQLi rules and a rate-based rule. Security groups cannot inspect HTTP payloads, and Shield focuses on DDoS rather than application query syntax.

1 Layer 7 filter→2 Managed rules→3 Rate limiting
WORKED SCENARIO

Rotate credentials automatically

A Lambda function needs database credentials that must rotate regularly without redeployment. Store them in Secrets Manager, enable rotation, and grant the function only secret retrieval and required KMS permissions. Environment variables alone retain static values, while Parameter Store standard parameters do not provide native managed rotation.

1 Managed rotation→2 Runtime retrieval→3 Least privilege
WORKED SCENARIO

Detect compromised credentials

Security needs managed detection of unusual API calls and known malicious network activity without deploying agents. Enable GuardDuty across accounts and Regions, then route findings through EventBridge for response. WAF sees only supported web traffic, and CloudTrail records API activity but does not itself perform threat analysis.

1 Threat analytics→2 No agents→3 Automated findings

06 · KNOWLEDGE CHECK

Twenty-five SAA-style questions

Q1A retail company serves a public website through an Application Load Balancer. Security logs show SQL injection payloads in HTTP POST bodies and thousands of requests per minute from individual client IPs. Packet filters on the instances cannot inspect query strings. The company needs Layer 7 blocking and per-IP throttling at the load balancer. Which solution will meet these requirements?
Answer: A. HTTP payload inspection plus per-client rate limits is AWS WAF. Shield is DDoS protection, and GuardDuty detects threats without filtering requests.

Good to know: Shield Advanced would be correct if the stem asked for DDoS response, DRT access, or attack cost protection. Network Firewall would be correct for VPC network traffic rather than ALB HTTP rules.
Q2A company runs Amazon RDS that application servers query from private subnets. Database credentials sit in deployment artifacts and change only when operators rebuild the fleet. Compliance requires the password to rotate on a schedule without a new deployment. Applications must retrieve the current secret at runtime using IAM. Which solution will meet these requirements?
Answer: C. Managed secret rotation and runtime retrieval select Secrets Manager. KMS protects encryption keys; it is not a rotating database-password store.

Good to know: Parameter Store standard parameters would be closer if the stem only needed a plaintext parameter without native managed rotation. KMS is the answer when the requirement is encryption keys, not secret values.
Q3A security team must detect unusual AWS API calls and traffic to known malicious IP addresses across several accounts. They will not deploy agents on Amazon EC2. The service must analyze CloudTrail, VPC Flow Logs, and DNS data and emit findings for automated response. HTTP filtering at the load balancer is already in place. Which solution will meet these requirements?
Answer: B. Agentless threat detection from CloudTrail, VPC Flow Logs, and DNS is GuardDuty. WAF already covers HTTP; it does not analyze those account telemetry sources.

Good to know: WAF would be correct for SQL injection or rate-based HTTP blocking. Macie would be correct for discovering sensitive data in Amazon S3, not Flow Logs.
Q4A company encrypts Amazon S3 objects with a customer managed AWS KMS key. An IAM role identity policy allows kms:Encrypt and kms:Decrypt, but the calls still fail with access denied. Service control policies do not deny KMS. The team must allow that role to use the key without making the key usable by every principal. Which solution will meet these requirements?
Answer: D. A KMS key policy is the foundational authorization document. An IAM allow fails when the key policy does not permit the principal or IAM delegation.

Good to know: If the key policy already enabled IAM policies for the account, adding the KMS actions on the role would have been enough. WAF and GuardDuty do not grant cryptographic permissions on a key.
Q5A media company already has Shield Standard on Amazon CloudFront. Large volumetric DDoS attacks caused extra scaling charges last quarter. Leadership wants 24/7 access to the AWS DDoS Response Team and cost protection for those attacks. SQL injection rules already run on AWS WAF and must remain. Which solution will meet these requirements?
Answer: A. DRT access and DDoS cost protection are Shield Advanced capabilities beyond Shield Standard. WAF remains the Layer 7 SQL injection control.

Good to know: Additional WAF rules would be correct if the remaining problem were HTTP floods or injection, not volumetric DDoS insurance and DRT. Inspector assesses workload vulnerabilities, not CloudFront DDoS.
Q6A media company stores large video objects in Amazon S3. Applications must use envelope encryption so AWS KMS protects short data keys while the service encrypts object bytes. Operators must create the key, set its key policy, and manage rotation. Using a key they cannot view or administer is not acceptable. Which solution will meet these requirements?
Answer: C. Envelope encryption with a key policy and rotation that the customer sets is a customer managed KMS key. AWS-owned keys cannot be viewed or administered.

Good to know: An AWS managed key (for example aws/s3) would fit if the stem only needed KMS with AWS-operated policy and rotation. Secrets Manager stores secret values, not S3 data-key envelopes.
Q7A company runs Amazon EC2 instances and stores container images in Amazon ECR. Security wants a managed service that continuously assesses those workloads for software vulnerabilities and network exposure. The team already has threat detection for CloudTrail anomalies and does not need PII discovery in Amazon S3. Which solution will meet these requirements?
Answer: B. Vulnerability and exposure assessment for supported compute and container workloads is Inspector. GuardDuty is threat detection, not a CVE scanner.

Good to know: GuardDuty would be correct for suspicious API or network behavior. Macie would be correct for sensitive data discovery in S3.
Q8A data lake in Amazon S3 holds objects from many business units. Compliance suspects some prefixes contain personal data and needs a managed service that discovers sensitive information in those objects. The team already uses GuardDuty for threat detection and does not need a web ACL on an Application Load Balancer. Which solution will meet these requirements?
Answer: D. PII and sensitive-data discovery in Amazon S3 is Macie. Inspector assesses compute and images; WAF does not attach to the S3 REST API.

Good to know: GuardDuty would be correct if the stem asked for threat detection from logs. WAF would be correct for SQL injection on CloudFront, ALB, or API Gateway.
Q9A company must inspect east-west and egress traffic inside a VPC using a managed firewall that applies stateful network rules. AWS WAF already protects the public Application Load Balancer. The new control must sit on VPC traffic, not only on HTTP to the load balancer. Operators will not run third-party appliances on Amazon EC2. Which solution will meet these requirements?
Answer: A. Central VPC network filtering is Network Firewall. WAF inspects HTTP at supported web fronts; GuardDuty detects and does not filter packets.

Good to know: WAF would be correct if the remaining gap were SQL injection or HTTP rate limits. Firewall Manager would appear if the stem required the same firewall policy across many accounts.
Q10An AWS Organizations administrator must apply the same AWS WAF web ACL policy to Application Load Balancers in dozens of member accounts. Teams must not attach ad-hoc ACLs that drift from the standard. The company already uses Organizations and wants AWS to enforce the policy centrally. Which solution will meet these requirements?
Answer: C. Firewall Manager centrally applies supported security policies, including WAF, across Organizations accounts and resources.

Good to know: A single-account WAF association would be enough if only one ALB needed rules. Detective investigates events; Artifact provides compliance reports.
Q11A company uses several AWS accounts. Security already receives findings from Amazon GuardDuty, Amazon Inspector, and Amazon Macie in separate consoles. Leadership wants one place that aggregates and normalizes those findings across accounts so analysts do not hop between products. Building investigation graphs is a later project. Which solution will meet these requirements?
Answer: B. Security Hub aggregates and normalizes findings from GuardDuty, Inspector, Macie, and other providers. Macie itself is a PII discovery source, not the multi-service aggregator.

Good to know: Amazon Detective would be correct if the stem asked to investigate related activity around a finding. Macie remains the S3 sensitive-data scanner.
Q12After Amazon GuardDuty reports a compromised IAM credential, analysts must investigate related CloudTrail activity, VPC flows, and resource relationships without building their own graph database. They already aggregate findings in AWS Security Hub. They need a managed investigation service, not another web ACL, and will not query raw log buckets by hand. Which solution will meet these requirements?
Answer: D. Detective is the managed investigation service for security events and related resource activity. Security Hub aggregates; it does not replace investigation.

Good to know: Security Hub would be the answer if the gap were a single findings console. WAF would be correct for malicious HTTP at a supported web front.
Q13A company terminates TLS on an Application Load Balancer and on an Amazon CloudFront distribution. It wants AWS to provision and automatically renew public certificates for those integrated services. The team will not install certificates on Amazon EC2 instances and will not export a public certificate to disk. Which solution will meet these requirements?
Answer: A. ACM provisions and renews public TLS certificates for supported AWS integrations such as ALB and CloudFront. Public ACM certificates are not installed on EC2 as exported PEM files.

Good to know: Secrets Manager plus a self-managed web server would appear if the stem required TLS on EC2 with a certificate the team can export. CloudHSM is the dedicated HSM answer, not public ACM issuance for CloudFront.
Q14A payments processor must run cryptographic operations on dedicated hardware security modules that the company controls, including key material that must not live only in AWS KMS. FIPS-validated HSMs are required. Customer managed KMS keys already encrypt Amazon S3 objects and are not sufficient for this isolated requirement. Which solution will meet these requirements?
Answer: C. Dedicated HSM appliances under customer control are CloudHSM. KMS customer managed keys are the usual encryption-key service, not dedicated HSMs.

Good to know: KMS would remain correct for envelope encryption and key policies without a dedicated-HSM mandate. ACM would be correct for TLS certificates on supported AWS integrations.
Q15Employees must sign in to the AWS access portal with corporate credentials. The company already uses Amazon Cognito user pools for a public mobile game and must not reuse that pool as the employee directory for AWS accounts. Game players are not AWS operators. Which solution will meet these requirements?
Answer: B. IAM Identity Center is workforce identity into AWS accounts. Cognito user pools are application customer identity, not the employee AWS directory.

Good to know: Cognito would be correct if the stem asked for mobile-app sign-up and JWT tokens for customers. Directory Service would appear if Windows workloads needed a managed Microsoft AD domain.
Q16A company is migrating an on-premises Active Directory-aware application to Amazon EC2. The servers must domain-join a managed Microsoft Active Directory in AWS for group policy. Amazon Cognito user pools already serve a separate mobile app and must not replace AD. Operators will not run domain controllers on Amazon EC2. Which solution will meet these requirements?
Answer: D. Directory Service managed Microsoft AD is the managed directory for domain-joined Windows workloads. Identity Center is workforce AWS access, not an AD domain for EC2.

Good to know: Cognito would be correct for application customer sign-in. Identity Center would be correct for employee SSO into AWS accounts rather than domain join.
Q17A compliance rule requires CloudTrail records when someone uses an encryption key, plus the ability to set a key policy and a customer-controlled rotation schedule. Objects live in Amazon S3. An AWS-owned key that the company cannot view would fail the audit. The security team must administer the key in the account. Which solution will meet these requirements?
Answer: A. Customer managed KMS keys provide a viewable key, a key policy, and customer-controlled rotation. AWS-owned keys are not visible or administrable in the account.

Good to know: An AWS managed key such as aws/s3 would fit if CloudTrail on key use were enough and the team did not need to edit the key policy. Macie discovers sensitive data; it does not replace encryption.
Q18A global site uses Amazon CloudFront in front of an Application Load Balancer. Attackers send SQL injection to the CloudFront URL. A WAF web ACL exists only on the ALB, and malicious requests still appear in CloudFront logs before they reach the origin. The company wants to block injection at the edge. Which solution will meet these requirements?
Answer: C. WAF inspects HTTP at CloudFront or ALB. A web ACL only on the origin never sees requests that the edge should have blocked. Shield does not replace WAF SQL rules.

Good to know: Keeping WAF only on the ALB would be enough if clients hit the load balancer directly. Shield Advanced would be correct for DDoS DRT and cost protection.
Q19A public Application Load Balancer receives SQL injection attempts and excessive requests from individual clients. The website runs on Amazon EC2 targets behind the load balancer in a VPC. Security groups cannot inspect HTTP payloads. Shield will remain in place for DDoS only and must not be the Layer 7 control. Which combination of steps should a solutions architect take? (Select TWO.)
Answer: A and C. WAF must be associated with the ALB, and the ACL needs SQLi plus rate-based rules. Those two steps are jointly required. Shield does not parse SQL.

Good to know: Shield Advanced would join the design if volumetric DDoS cost protection or DRT access were also required. Macie is S3 sensitive-data discovery.
Q20A Lambda function in a VPC needs Amazon RDS credentials that must rotate without redeployment. The password currently sits in an environment variable baked into the deployment artifact. A teammate proposed putting the password in a KMS key alias. The function must retrieve the current value at runtime with least privilege. Which combination of steps should a solutions architect take? (Select TWO.)
Answer: B and D. Secrets Manager stores and rotates the credential; the execution role must be allowed to retrieve it. KMS is for keys, not a rotating password value.

Good to know: Parameter Store standard parameters would not supply native managed rotation. A KMS grant would appear if the function only needed to decrypt data keys.
Q21Security needs managed detection of unusual API calls and known malicious network activity without deploying agents. CloudTrail is already enabled. Findings must fan out to an automated response workflow. HTTP filtering at the ALB is already handled by AWS WAF. Which combination of steps should a solutions architect take? (Select TWO.)
Answer: C and E. GuardDuty provides agentless threat analytics on CloudTrail and related logs. EventBridge is how those findings drive automated response.

Good to know: Inspector would be correct for vulnerability assessment of compute. WAF would be correct if the remaining gap were SQL injection or HTTP rate limits.
Q22An application on Amazon EC2 uses an IAM role to encrypt and decrypt Amazon S3 objects. The team must administer the key, including its key policy. An AWS-owned key cannot receive a custom key policy. Calls must succeed for that role only. Which combination of steps should a solutions architect take? (Select TWO.)
Answer: A and E. Only a customer managed key lets the team set a key policy, and that policy must allow the application role. IAM alone is not sufficient without it.

Good to know: An AWS managed key would fit encryption without customer key-policy control. Secrets Manager would be correct for a rotating database password.
Q23Critical applications behind Amazon CloudFront suffered DDoS-related scaling charges. The company still sees SQL injection in access logs and must keep Layer 7 rules. Leadership wants DDoS Response Team access and cost protection. The applications must remain on CloudFront. Which combination of steps should a solutions architect take? (Select TWO.)
Answer: B and C. Shield Advanced adds DRT and cost protection. WAF remains required for SQL injection and HTTP rate limits; Shield does not replace those rules.

Good to know: Shield Standard would already cover baseline DDoS on supported services but not DRT or cost protection. Macie discovers sensitive data in S3.
Q24Compliance must discover personal data in Amazon S3 and view those findings next to Amazon GuardDuty findings in one console. The data lake already holds objects from several business units in one Region. Analysts must not open a separate Macie-only workflow as the long-term operating model. Which combination of steps should a solutions architect take? (Select TWO.)
Answer: D and E. Macie discovers sensitive data in S3. Security Hub is the aggregator that places those findings beside GuardDuty in one console.

Good to know: Detective would be the next step if the stem asked to investigate a finding's related activity. WAF does not attach to the S3 REST API.
Q25An Organizations administrator must inspect VPC traffic with a managed network firewall and apply that policy across many member accounts. AWS WAF already covers HTTP at the Application Load Balancer. Teams must not deploy one-off firewall appliances per account. Which combination of steps should a solutions architect take? (Select TWO.)
Answer: A and B. Network Firewall filters VPC traffic; Firewall Manager applies that supported policy centrally across Organizations. WAF does not replace VPC packet inspection.

Good to know: A single-VPC Network Firewall deployment would suffice without Organizations scope. WAF would remain the answer for SQL injection at the ALB.
