AWS Solutions Architect Associate
Unofficial Study Aid

17 Structured Lessons to help you prepare for the AWS Solutions Architect Associate (SAA-C03) exam. Each lesson has a visual map, an architecture drawing, decision tables, worked scenarios, exam-language triggers, and scenario-style questions.

As outlined in the SAA-C03 exam guide, the exam is weighted across the following domains:

30%
Security

Secure access, workloads/applications, and data controls.

26%
Resilience

Loose coupling, scalability, HA, fault tolerance and DR.

24%
Performance

Storage, compute, databases, networks and data ingestion.

20%
Cost

Cost-optimized storage, compute, database and networking.

How to use this course: For each lesson, draw the architecture, then explain the packet/data path, failure mode, scaling mechanism, and cost trade-off without notes. Then take the quiz.
1 · DRAW

Reproduce the architecture drawing from memory before reading the deep dive.

2 · TRACE

Follow request and data paths; name the control that permits or blocks traffic.

3 · STRESS

Ask what fails in an AZ or Region outage and how RPO/RTO change.

4 · DECIDE

Use exam language triggers to eliminate answers that violate hard constraints.
